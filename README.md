# SVT Realtime Stop Tracker
A website to show **realtime data** of your **saved stops** of the _SVT_ network.

It uses data from the links available at every stop at the _"Scansiona QR code per le partenze in tempo reale"_ and **aggregates** them for **easier accessibility**.

## Functionality
In the [website](https://superma30.github.io/SVT-realtime-stop-tracker/) there is a search bar to search a stop by its code (for example: _490_ is the code of _Stazione FS_). When searched you can the SVT-updated data and save the stop. When saved you can edit a custom name for it and you can remove it. Saved stops are stored in your browser so when changing device or browser the data won't transfer. In supported devices and browsers the "Download App" appears which allows to download the WebApp (Same functionality as the website).
